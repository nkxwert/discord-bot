개인정보 보호 정책

시행일: 2026년 11월 2일

이 정책은 디스코드 봇 "마코(maco)"(이하 "봇")이 어떤 정보를 저장하고, 어디로 보내며, 어떻게 지울 수 있는지 설명합니다.

1. 저장하는 정보

기능저장하는 정보보관 기간
서버 등록 (!주소추가)디스코드 서버 ID, 등록한 사용자의 디스코드 ID, 마인크래프트 서버 주소와 이름, 등록 시각삭제할 때까지
업타임 기록확인 시각, 온라인 여부, 응답 시간30일 후 자동 삭제
이스터에그디스코드 서버 ID와 이름, 등록한 명령어와 문장 (등록한 사람은 저장하지 않음)삭제할 때까지

봇은 명령어를 처리하기 위해 메시지 내용을 읽지만, 위 표에 적은 것 외의 메시지 내용은 저장하지 않습니다.

전적 조회 결과는 같은 요청을 줄이기 위해 봇 메모리에 5분 동안만 보관하며, 파일로 저장하지 않습니다.

봇 운영 상황을 확인하기 위해 디스코드 서버별 메시지 수와 명령어 사용 수를 봇 메모리에서 최근 24시간 동안만 집계합니다. 개수만 세며 메시지 내용이나 보낸 사람은 기록하지 않고, 봇이 다시 시작되면 사라집니다.

오류가 나면 원인을 찾기 위해 서버 주소나 오류 내용이 봇의 실행 로그에 남을 수 있으며, 오류 내용과 함께 해당 명령어, 디스코드 서버 이름, 사용자 이름과 ID가 봇 관리자에게 디스코드 DM으로 전달될 수 있습니다.

2. 외부 서비스로 보내는 정보

서비스보내는 정보보내는 때
등록한 마인크래프트 서버상태 확인 요청주기적으로, !업타임 사용 시

각 서비스가 받은 정보를 어떻게 처리하는지는 해당 서비스의 정책을 따릅니다. 봇 운영자는 정보를 판매하거나 위 목적 외로 다른 곳에 제공하지 않습니다.

3. 저장 위치

정보는 봇을 실행하는 호스팅 서버에 저장됩니다.

4. 정보 삭제

  • 등록한 서버와 업타임 기록: 서버 관리 권한이 있는 사람이 !주소삭제 <이름>으로 지울 수 있습니다.
  • 이스터에그와 그 밖의 정보: 아래 문의처로 요청하면 지웁니다.
  • 봇을 서버에서 내보내도 저장된 정보는 자동으로 지워지지 않으니, 지우려면 내보내기 전에 삭제하거나 요청해 주세요.

5. 정책의 변경

정책은 필요에 따라 바뀔 수 있으며, 바뀐 정책은 이 페이지에 게시한 때부터 적용됩니다.
