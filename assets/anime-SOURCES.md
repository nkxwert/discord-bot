# anime.json 출처

애니캐 맞히기(`quiz.py`)의 캐릭터 목록입니다. 52개 작품, 309명.

- 작품은 사용자 추천 목록(25개)과 한국에서 많이 본 작품(27개)으로 골랐습니다.
- 캐릭터 번호, 영어·일본어 이름, 그림 주소: [AniList](https://anilist.co) API. 캐릭터는 작품별 AniList 인기(즐겨찾기) 순 상위에서 골랐습니다.
- 한글 이름과 흔히 부르는 이름(예: 봇치, 아랴, 데쿠): 정식 한국어판 표기를 따르고, 없으면 일본어 발음대로 적었습니다.
- `star`: 쉬움에 나오는 누구나 아는 대표 캐릭터.
- 캐릭터 그림은 저작권자의 것이라 봇 폴더에 저장하지 않습니다. 문제를 낼 때마다 AniList에서 받아 `캐릭터.png`로 올리고 바로 버립니다.
