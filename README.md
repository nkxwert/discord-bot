# Minecraft 업타임 디스코드 봇

디스코드 서버마다 Minecraft Java Edition 서버를 최대 10개까지 등록하고, 누구나 `!업타임`으로 상태를 확인할 수 있습니다.

## 명령어
- `!주소추가 hypixel.net 하이픽셀` — 서버 추가 (이름은 생략 가능, 누구나 사용 가능)
- `!업타임` — 등록된 모든 서버의 상태와 24시간/7일 업타임
- `!업타임 하이픽셀` — 서버 하나의 자세한 업타임 (이름 또는 주소)
- `!주소` — 등록된 서버 목록
- `!주소삭제 하이픽셀` — 서버와 기록 삭제 (서버 관리 권한 필요)
- `!H전적 hypixel` — 하이픽셀 전적 카드 (이미지). `bw`, `sw`, `duels`를 붙이면 게임별 전적
- `!V전적 Hide on bush#KR1` — 발로란트 전적 카드 (이미지). 랭크 아이콘·RR, 최고 랭크, 최근 10경기 승률·K/D·헤드샷·ADR(데스매치 제외), 최근 5경기. 지역은 계정에서 자동으로 찾으며 직접 붙일 수도 있음 (`kr`·`ap`·`na`·`eu`·`latam`·`br`). 계정을 못 찾으면 헷갈리기 쉬운 글자(I/l/1, O/0)를 바꾼 비슷한 ID를 버튼으로 제안
- `!개발자소통` — 개발자에게 메시지 보내기. 봇이 DM으로 물어보고, DM에 쓴 내용과 사진을 전달 (`/도움말`의 ✉️ DM to Dev.를 누르면 나만 보이는 입력 창: 종류·제목·내용·사진 3장). 개발자가 답장하면 DM으로 받고, DM의 [답장하기]로 다시 보낼 수 있음. 5분에 한 번
- `!올리기 [이름]` + 파일 첨부 — 파일을 저장소(Backblaze B2 등)에 올리고 미리보기 카드로 보냄 (사진은 바로 보이고 영상과 노래는 채팅창에서 재생, 긴 링크는 [원본 열기] 버튼 안에, 한 번에 5개까지). 첨부 없이 쓰면 큰 파일(최대 5GB)용 업로드 페이지 링크를 DM으로 보내고, 페이지에서 올리면 자동으로 채널에 올림([업로드 완료]는 예비). 누구나 사용, 10초에 한 번
- `!파일 [이름]` — 내가 올린 파일 목록 / 이름을 붙이면 그 파일 미리보기
- `!파일삭제 <이름>` — 내가 올린 파일만 지울 수 있음
- 파일 관리자(봇 관리자 + `£DB 관리자`로 추가한 사람)는 모든 사람의 파일을 보고 지울 수 있음
- 올린 파일은 **7일(관리자가 `£DB 기간`으로 변경 가능) 후 자동 삭제**되며, 올릴 때마다 안내함
- `!운세` — 오늘의 운세 (칠 때마다 무작위). 문장은 `fortunes.txt`에 한 줄에 하나씩 있으며, 메모장으로 고치면 재시작 없이 바로 적용
- `!일침` — 정신이 번쩍 드는 한마디 (칠 때마다 무작위). 문장은 `ilchim.txt`
- `!dday [이름]` — 이 서버의 D-Day 목록, 이름을 붙이면 그 날까지 남은 시간 (누구나 볼 수 있음)
  - 만들기·편집·삭제는 `/도움말` → 기타 → D-Day (편집·삭제는 만든 사람만). 서버당 25개, 한 사람 10개
- `!나라시작 [쉬움|보통|어려움]` — 나라 맞히기: 봇이 몰래 고른 나라를 채널의 모두가 함께 맞힘 (채널마다 한 판, 진행 중이면 이어서)
  - 쉬움: 잘 알려진 나라 80개 중 하나 · 보통: 197개 나라 중 무작위 (둘 다 횟수 제한 없음)
  - 어려움: 나머지 덜 알려진 나라 중 하나, 10번 안에. 표는 대륙·내륙국·이웃(정답과 국경이 닿는지)·평균 기온·인구·면적 (기온·인구·면적은 ▲▼만)
  - `!추측 <나라>` — 추측할 때마다 대륙·인구·면적·거리·방향·반구·내륙국 힌트 표(그림)가 올라옴
  - `!포기` — 정답 공개 · `!나라순위` — 쉬움·보통·어려움 승리 수 순위
  - `/도움말` → 🎮 게임 → 나라 맞히기에서 쉬움·보통·어려움 시작, 순위, 나라 정보
- `!국기시작 [쉬움|보통|어려움] [문제 수]` — 국기 맞히기: 국기 그림을 보고 `!국기 <나라>`로 답함. 가장 먼저 맞힌 사람의 개수가 난이도별로 기록됨 (시간·횟수 제한 없음, 기본 10문제, 최대 50)
  - 쉬움: 잘 알려진 나라 · 보통: 모든 나라 · 어려움: 덜 알려진 나라, 비슷하게 생긴 국기가 자주 나옴
  - `!힌트` — 초성 힌트 · `!국기스킵` — 넘기기 · `!국기중지` — 그만 · `!국기순위` — 쉬움·보통·어려움 맞힌 개수 순위
  - 국기 그림: `assets/flags/` (flagcdn.com, 퍼블릭 도메인). 파일 이름은 항상 `국기.png`로 올려 답이 드러나지 않음
- `!수도시작 [쉬움|보통|어려움] [문제 수]` — 수도 맞히기: 나라가 나오면 `!수도 <수도>`로 답함. 가장 먼저 맞힌 사람의 개수가 난이도별로 기록됨 (국기 맞히기와 같은 방식)
  - 수도 이름은 정확히 (흔한 다른 표기·영어 이름도 정답, 수도가 여럿인 나라는 그중 하나)
  - `!힌트` — 진행 중인 퀴즈(국기·수도)의 초성 · `!수도스킵` · `!수도중지` · `!수도순위`
- `!지도시작 [쉬움|보통|어려움] [문제 수]` — 지도 맞히기: 지도를 보고 `!지도 <나라>`로 답함 (국기 맞히기와 같은 방식)
  - 쉬움·보통: 주변이 보이는 지도에 정답 나라가 빨간색 (아주 작은 나라는 빨간 동그라미) · 어려움: 나라 모양(실루엣)만, 2,500㎢ 미만의 아주 작은 나라는 제외
  - 그림: `assets/maps/` (Natural Earth, 퍼블릭 도메인 · `assets/maps/SOURCES.md`) · `!지도스킵` · `!지도중지` · `!지도순위`
- `!캐릭시작 [쉬움|보통] [문제 수]` — 애니캐 맞히기: 애니 캐릭터 그림을 보고 `!캐릭 <이름>`으로 답함 (52개 작품, 309명)
  - 쉬움: 대표 캐릭터 54명 · 보통: 전체 · 이름만(`탄지로`)·영어·일본어 이름도 정답 · `!힌트` 작품 → 초성
  - 그림은 문제마다 AniList에서 받아 올림 (봇 폴더에 저장 안 함) · 목록: `assets/anime.json` (`assets/anime-SOURCES.md`)
- `!나라출제` (`!나라 출제`) — 버튼 → 나만 보이는 입력 창에 나라와 규칙(보통/어려움)을 정하면, 다른 사람들이 맞히는 나라 맞히기 판이 열림 (출제자는 추측 불가, 순위에는 안 들어감)
- `!정보 <나라>` (`!나라정보`) — 나라 소개(한국어 위키백과 요약, 하루 캐시)와 국기·대륙·수도·인구·면적(한국과 비교)·인구 밀도·바다·언어·통화·이웃 나라
  - 나라 데이터: `assets/countries.json` (출처: `assets/countries-SOURCES.md`)
  - 입력: 이름, 날짜(한국 시간, `2027-11-18` 또는 `2027-11-18 08:40`, `11-18`도 됨), 표시 문구, 자동 알림 시각, 알림 채널. 만든 뒤 "날짜가 지나면"(D+로 계속 / 당일 축하 후 알림 끝 / 당일 축하 후 삭제)을 고름
  - 🎉 축하 문구: 만들거나 편집한 뒤 나오는 버튼으로 당일 문구를 정함 (칸: `{이름}` `{D}`, 비우면 "🎉 오늘이 **{이름}**입니다! (D-DAY)"). 당일 자동 알림에도 이 문구가 쓰임
  - 문구 칸: `{이름}` `{D}` `{년}` `{월}` `{일}` `{시}` `{분}` `{초}` — 쓴 칸으로 남은 시간을 나눔 (`{일}` → 400일, `{년} {월} {일}` → 1년 1개월 5일, 앞자리 0은 생략). 이미 지난 날짜로 만들면 지난 시간을 셈 (`{이름} {D} ({일}째)` → 사귄 날 D+320 (320일째))
  - 자동 알림: 매일 정한 시각에 고른 채널로 보냄. 봇이 꺼져 있던 동안 놓친 알림은 켜진 뒤 한 번만 보냄
- `/글자콘 글자:<글자> [메시지:<메시지>]` — 글자를 디시 글자콘처럼 그림(흰 글자·검은 테두리, 투명 배경)으로 만들어 올림. 최대 30자, 길면 여러 줄로 나눔. `/unflip`처럼 메시지를 같이 넣을 수 있고, **내 이름과 프로필 사진으로** 올라감(웹훅이라 이름 옆에 "앱" 표시. 봇에 **웹훅 관리** 권한이 없거나 DM이면 봇 이름으로 올림). 이모지는 그릴 수 없어 빠짐
- `!도움말` — 명령어 안내
- `/도움말` — 나만 보이는 버튼 도움말 (메시지 1개). [서버 업타임]·[전적]·[파일]·[기타(운세·일침)]·[DM to Dev.]·[명령어 보기(`!도움말`과 같은 전체 목록)]를 누르고, 명령어 버튼을 누르면 바로 실행 (주소추가·Hypixel 전적·Valorant 전적은 입력 창, 주소삭제는 목록에서 고르기). 업타임·전적 카드 같은 결과는 `!` 명령어처럼 채널에 보이고, `주소` 목록과 안내 문구는 도움말 메시지 안에 표시. 배너 이미지는 `assets/images/help_banner.jpg`(GitHub 주소로 표시, 바꾸려면 `.env`의 `HELP_BANNER_URL`), 전적 버튼 아이콘은 `assets/emojis/`(봇이 처음 켜질 때 봇 전용 이모지 `maco_hypixel`·`maco_valorant`로 자동 등록. 이미지를 바꾸면 Developer Portal → Emojis에서 지운 뒤 재시작)

## 봇 설정
1. Discord Developer Portal에서 봇을 만들고 **Message Content Intent**를 켭니다.
2. OAuth2 URL Generator에서 `bot`, `applications.commands` 스코프와 아래 권한을 선택해 초대합니다. (`applications.commands`는 `/도움말` 같은 슬래시 명령어용이며, 예전 링크로 초대한 서버는 새 링크로 다시 초대하면 됩니다. 다시 초대해도 봇이 나가지 않습니다.)
   - View Channels, Send Messages, Embed Links, Attach Files, Read Message History (권한 값 `117760`)
   - 이미 초대한 봇은 서버 설정 → 역할에서 봇 역할에 **파일 첨부** 권한을 켜면 됩니다.

## 전적 API 키
- `HYPIXEL_API_KEY`: developer.hypixel.net에서 발급합니다. 개발용 키는 약 3일마다 만료되므로 계속 쓰려면 Personal 키를 신청하세요.
- `HENRIK_API_KEY`: HenrikDev 디스코드에 들어간 뒤 https://api.henrikdev.xyz/dashboard/ 에서 Basic 키를 발급합니다.
- 키는 `.env`(또는 호스팅의 환경변수)에만 넣고 GitHub에 올리지 마세요. 키가 없으면 해당 명령어만 안내 문구를 보여 줍니다.

## 파일 저장소 (Backblaze B2 추천, 카드 없이 무료 10GB)
S3 호환 저장소라면 어디든 쓸 수 있습니다. 아래는 Backblaze B2 기준입니다.
1. https://www.backblaze.com 에서 **B2 Cloud Storage**로 가입합니다. 가입 버튼 아래의 지역을 **US West**로 고릅니다. (나중에 바꿀 수 없음)
2. **Buckets → Create a Bucket**에서 버킷을 만듭니다. **Files in Bucket are: Private**(비공개)로 두면 됩니다. 봇이 7일짜리 서명된 링크를 만들어 보내므로 공개 버킷이 필요 없습니다. (B2는 공개 버킷에 결제 이력을 요구합니다)
3. 버킷의 **Lifecycle Settings**를 **Keep only the last version of the file**로 바꿉니다. B2는 지운 파일을 숨김 버전으로 남겨 두기 때문입니다. (봇도 지울 때 숨김 버전까지 지웁니다)
4. 버킷 정보의 **Endpoint**(예: `s3.us-west-004.backblazeb2.com`)를 확인합니다.
5. **Application Keys → Add a New Application Key**에서 이 버킷만, **Read and Write** 권한으로 키를 만듭니다. `keyID`와 `applicationKey`는 한 번만 보여 주니 바로 복사합니다.
6. `.env`에 넣고 봇을 재시작합니다.
   ```
   STORAGE_ENDPOINT=https://s3.us-west-004.backblazeb2.com
   STORAGE_ACCESS_KEY_ID=keyID
   STORAGE_SECRET_ACCESS_KEY=applicationKey
   STORAGE_BUCKET=버킷이름
   ```
- 봇이 켜질 때 큰 파일 업로드 페이지(`assets/upload.html`)를 버킷에 올리고 CORS 규칙을 설정합니다. 브라우저는 같은 주소에 올릴 때도 `Origin`을 보내고 B2는 그때 CORS 규칙을 확인하기 때문에, 비공개 버킷에도 필요합니다.
- B2에서는 웹 업로드 페이지가 Backblaze가 안내하는 브라우저 업로드 방식(B2 고유 API `b2_upload_file`)을 씁니다. S3 방식의 서명 링크는 브라우저에서 B2가 `400 InvalidRequest`로 거절했기 때문입니다. 봇이 켜질 때 이 방식용 CORS 규칙을 버킷에 넣고(`b2_update_bucket`), B2 API가 안 되면 서명 링크로 대신합니다. B2 업로드 토큰은 24시간 유효하므로, 봇이 6시간마다 목록에 없는 저장소 파일(2시간 이상 된 것)을 지웁니다.
- `£DB 테스트`로 봇 업로드·서명 링크·웹 업로드(CORS)·B2 고유 업로드가 되는지 실제로 확인할 수 있습니다. "CORS 규칙 설정"이 🔴이면(키에 버킷 설정 권한이 없는 경우) B2 웹사이트에서 직접 넣어 주세요: Buckets → 버킷의 **CORS Rules** → **Custom Rules** → 허용 주소에 `https://s3.us-west-004.backblazeb2.com`(내 Endpoint), **S3 Compatible API** 선택, 메서드 PUT·GET·HEAD, 헤더 `*`.
- B2 무료 범위: 저장 10GB, 다운로드는 저장량의 3배까지, 하루 다운로드 요청 2,500회 등. 카드가 없으면 넘었을 때 요금 대신 막힙니다.
- 다른 저장소: 공개 버킷을 쓰려면 `STORAGE_PUBLIC_URL`에 공개 주소를 넣습니다(이때 CORS가 필요하며 봇이 설정을 시도합니다). Cloudflare R2는 예전 설정(`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_URL`)도 그대로 동작합니다.
- 사진·영상·음악은 바로 보이게, 그 밖의 파일(HTML 등)은 열리지 않고 다운로드만 되게 저장합니다.
- 노래(mp3, m4a, ogg, wav, flac 등)는 카드에서 올린 사람이 보여 줄 방식을 고릅니다.
  - **바 형태 (빠르게)**: 노래 파일을 메시지에 그대로 첨부해 디스코드 음악 재생 바로 보여 줌. 바로 올라가지만 서버의 첨부 한도(부스트 없으면 10MB, 2레벨 50MB, 3레벨 100MB) 이하만 됨. 그 메시지는 파일이 지워질 때 같이 지워짐
  - **영상 형태**: 봇이 **재생용 MP4**를 만들어 카드에서 재생(앨범 아트가 있으면 그 그림, 없으면 마코와 노래 제목 + 노래 소리). 크기 제한이 없지만 큰 노래는 만드는 데 시간이 걸림. 재생용 파일은 서버 용량 한도에 세지 않고, 노래를 지울 때 같이 지워짐
  - ffmpeg가 필요합니다. 호스팅에 없으면 `requirements.txt`의 `imageio-ffmpeg`가 같이 설치해 줍니다(디스크 약 170MB). `£DB`의 "노래 재생"에서 확인할 수 있습니다.
  - 메모리: 한 번에 한 곡씩, ffmpeg가 잠깐 최대 약 45MB를 씁니다. 4분 노래 기준 4초쯤 걸립니다. 일본어 한자 등 글꼴에 없는 글자는 제목 그림에서 빠집니다.
- 영상 변환은 기본으로 꺼져 있습니다. `.env`에 `FILE_CONVERT_VIDEO=true`를 넣고 호스팅에 `ffmpeg`가 있으면 아이폰 영상(MOV·HEVC) 등 디스코드에서 재생되지 않는 영상을 MP4(H.264)로 바꿔서 올립니다. 변환은 메모리를 많이 써서 128MB 호스팅에서는 켜지 않는 것을 권장합니다.
- 파일은 메모리에 통째로 담지 않고 조금씩 저장소로 흘려보내므로, 큰 파일을 올려도 봇의 메모리 사용량은 거의 늘지 않습니다.
- 한도: 서버마다 **서버 전체 용량**과 **파일당 최대 크기**를 봇 관리자가 `£DB 한도`로 정합니다(DB에 저장, 재시작해도 유지). `.env`의 `FILE_GUILD_QUOTA_MB`(기본 10GB)·`FILE_MAX_MB`(기본 5GB)는 처음 기본값이고, 봇 전체 한도는 `FILE_TOTAL_QUOTA_MB`(기본 10GB)입니다. 크기는 마음대로 정하거나 **한도 없음**으로 둘 수 있습니다. 다만 저장소가 한 번에 받을 수 있는 건 5GB라 파일 하나는 5GB를 넘을 수 없고, 모든 서버를 합쳐 봇 전체 한도 안에서만 올라갑니다. 업로드 페이지는 한도보다 큰 파일을 올리기 전에 막고, 봇이 올린 뒤에도 다시 확인합니다. 디스코드 첨부는 서버 부스트에 따라 더 작은 제한이 있어 큰 파일은 업로드 페이지를 씁니다.

## 단축 링크 (NKOTE, nnaco.kro.kr)
업로드 페이지 링크와 파일의 [원본 열기]·[다운로드] 버튼을 `nnaco.kro.kr/xxxxxxxxxx`처럼 짧게 줄입니다. 사진·영상 미리보기는 원래 저장소 주소를 씁니다.
1. [NKOTE](https://github.com/nkxwert/NKOTE)를 Vercel에 배포하고 nnaco.kro.kr을 연결합니다. (NKOTE README 참고. 봇 소개·약관·개인정보 페이지도 NKOTE가 제공합니다)
2. `nnaco.kro.kr/manage`에 관리자 키로 접속해 **API 키 발급**에서 봇용 키를 만듭니다.
3. `.env`에 `NKOTE_URL=https://nnaco.kro.kr`, `NKOTE_API_KEY=nk_…`를 넣고 재시작합니다.
- 링크는 10자리 무작위 주소이고, 업로드 링크는 1시간 뒤, 파일 링크는 파일과 같은 시각에 만료됩니다. 파일을 지우면 단축 링크도 지웁니다.
- 업로드 페이지는 업로드가 끝나면 NKOTE에 신호를 보내고, 봇은 그 신호를 몇 초마다 확인해 채널에 "⏳ 파일 불러오는 중..."을 띄운 뒤 파일 카드로 바꿉니다. (NKOTE가 없으면 저장소를 직접 확인하며 최대 30초쯤 걸립니다)
- NKOTE가 응답하지 않으면 긴 링크를 씁니다. `£DB 테스트`에서 단축 링크 만들기·열기를 확인할 수 있습니다.
- 이 저장소의 `index.html`·`terms.html`·`privacy.html`·`CNAME`(GitHub Pages)은 nnaco.kro.kr을 Vercel로 옮긴 뒤에는 쓰이지 않습니다.

- `£` 명령어도 그대로 쓸 수 있습니다.

## 메모리 (128MB 호스팅)
- 봇은 메모리를 아끼도록 설정되어 있습니다: DB 연결을 쓰자마자 닫음, 저장소 통신을 boto3 없이 직접 처리, 파일은 조금씩 흘려보냄, 통신 세션 공유, 디스코드 메시지 캐시 끔, 작업 스레드 2개, 메모리 할당기 조정(arena 2개, 큰 버퍼는 바로 반납), 전적 캐시·폰트 캐시 상한.

## 참고
- Java Edition 전용이며, 서버 목록은 디스코드 서버별로 따로 저장됩니다.
- 이전 버전(주소 1개)의 데이터는 실행 시 자동으로 옮겨지며, 이름은 주소로 설정됩니다.
- 업타임은 봇이 수집한 표본 기준이라 봇이 꺼진 시간은 측정되지 않습니다.
- 호스팅 IP가 차단되어 직접 조회가 실패하면 마지막 수단으로 외부 서비스(mcsrvstat.us)로 확인합니다. 도메인 주소만 전송하며 IP 주소는 절대 보내지 않습니다. 외부 조회 결과는 응답 시간이 없고 몇 분 캐시될 수 있습니다. `.env`의 `EXTERNAL_FALLBACK=false`로 끌 수 있습니다.
- 확인 간격은 `.env`의 `CHECK_INTERVAL_SECONDS`로 조절합니다. (기본 10초, 최소 1초)
- API 키 만료·요청 한도 초과·외부 서비스 장애나 예상치 못한 오류가 나면 봇 관리자(`.env`의 `BOT_OWNER_IDS`, 비우면 봇을 만든 계정)에게 DM으로 알립니다. 같은 오류는 10분에 한 번만 보냅니다. 봇과 같은 서버에 있어야 DM을 받을 수 있습니다.
- 봇 관리자 전용 명령어 (다른 사람이 치면 아무 반응 없음). `£도움말`로 목록을 볼 수 있습니다.
  - `£servers` — 참여 중인 서버와 24시간 메시지·명령어 수
  - `£DB` — 로컬 DB와 파일 저장소 상태 (연결·응답 시간, 사용/남은 용량, 파일 수, 다음 자동 삭제 등)
  - `£DB 파일 [서버ID]` — 올라간 파일과 번호 · `£DB 삭제 <번호...>` — 번호로 삭제 · `£DB 서버삭제 <서버ID>` — 그 서버 파일 전부 삭제(확인 버튼)
  - `£DB 만료 <번호> <기간>` — 파일 하나의 만료일을 지금부터 그 기간 뒤로 바꾸기 (예: `£DB 만료 12 3일`). 단축 링크는 주소 그대로 새 만료일까지 열림
  - `£DB 기간 [기간]` — 자동 삭제 기간 보기/바꾸기 (기본 7일, 1시간~7일, 공개 저장소는 30일까지). 새로 올리는 파일부터 적용
  - `£DB 정리` — 기간 지난 파일 즉시 삭제 + 목록에 없이 저장소에만 남은 파일 정리
  - `£DB 관리자 [추가|삭제] [사용자]` — 파일 관리자(모든 사람의 파일을 보고 지울 수 있음) 보기/바꾸기. 봇 관리자는 항상 포함
  - `£DB 한도 [서버ID|여기]` — 서버별 한도와 사용량 보기 · `£DB 한도 <서버ID|여기> 용량 2GB 파일 500MB` — 그 서버 한도 바꾸기. 크기는 마음대로(`300KB`, `1.5GB`, `2TB` …), `없음`은 한도 없음, `기본`은 기본값으로, `초기화`는 둘 다 되돌리기 · `£DB 한도 기본 파일 1GB` — 기본 한도 바꾸기
- 전적 결과는 API 한도를 아끼기 위해 5분간 캐시되며, 같은 사용자는 5초에 한 번 조회할 수 있습니다.
